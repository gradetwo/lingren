# 和声附加评估：用两个模型本身的差异做和声（Wang 2026-11-02 ~09:09 新增）

地位：附加评估，不替代独立乐谱路线。独立乐谱路线（每 part 写自己的
note_pitch、同 voice_id 合成）仍是和声的主路线，本条只评估模型差异
本身能否给和声声部提供天然区分度。

## 待验问题

同一乐谱分别用 SoulX 与 VocalRender 生成，量三类差异：

1. 音色差异：包络 log-RMS 相关度（跨模型应显著低于同模型换 seed 的
   0.94，否则“两个歌手”的说法不成立）；频谱质心均值差；峰值/RMS 形态。
2. 时钟差异：VocalRender 总时长相对乐谱推算时长的偏差（Phase 0 为
   ±5% 内）；SoulX 按乐谱时钟（中位边界偏差 70 ms）。跨模型贴轨时，
   和声部（VR）相对主旋律（SoulX）的乐句级漂移量 = VR 总时长偏差在乐句
   长度上的累积（例：60 s 乐句 × 5% = 3 s 级漂移，不可忽略）。
3. 音高行为差异：同乐谱同 prompt，两模型输出 F0 中位差（Phase 0 各自
   都跟乐谱音高范围吻合，但跨模型中位差未量过）；VR 无 auto_shift 类
   机制，SoulX 须关 auto_shift 才能比绝对音高。

## 实验设计（Colab L4 同会话内跑）

- 输入：同一短乐谱（8–12 音符，含 2–3 个音高变化边界）+ 同一段 prompt
  参考音频（SoulX 用 zh_prompt 体系，VR 用官方 prompt 音频；prompt 不
  同是已知混杂因素，结论里必须注明：prompt 不同时音色差不能全归因
  于模型）。
- 组 A（主评估）：同乐谱原调，SoulX（auto_shift 关）vs VR 各一遍，
  量包络相关度、F0 中位差、总时长差、频谱质心差。
- 组 B（和声模拟）：主旋律 SoulX 原调 + 和声 VR 独立乐谱（+4 半音），
  按“主旋律乐谱时钟 + 和声实测起点”贴轨，量和声部各音节相对乐谱
  的漂移分布，判断合唱感是否成立、漂移是否可接受。
- 对照：同模型换 seed 的差异量级（Phase 0 已有：SoulX 包络 0.94、
  F0 差 10–20 音分），跨模型差异必须显著大于同模型差异，才算“天然
  区分度”。

## 结论写进 phase1 报告的条目

- 差异量级（实测数表）。
- 是否可用：可用作音色区分手段，还是差异主要来自时钟漂移（负作用）。
- 与独立乐谱路线相比的优劣：独立乐谱路线解决“音高不同”，模型分
  轨解决“音色不同”，两者正交，可叠加；模型分轨不能单独解决和声
  （不改音高就没有和声），也不能替代独立乐谱路线。
- 建议：主推 = 独立乐谱路线；模型分轨 = 可选的音色分层手段，和声
  部用另一模型时必须按实测起点贴轨并在回执里标出跨模型时钟差。
